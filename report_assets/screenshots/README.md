# Report Screenshot Set

This folder contains report ready images captured from the assembled local application with synthetic Bangladeshi names. No real patient data, password, MFA seed, session value, API key, or private source document may appear in these images.

The final capture set covers the public service, doctor directory, patient dashboard, appointment availability, patient assistant, receptionist operations, checked in queue, doctor workload, doctor queue console, administrator overview, schedule administration, and audit trail.

Each image uses a numbered file name so it can be inserted into the project report in workflow order. The browser viewport is kept consistent wherever the page layout permits it.
